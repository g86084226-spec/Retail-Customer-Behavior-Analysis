# Retail Customer Behavior & Shopping Trends

## Project Overview
This project analyzes retail customer behavior and shopping trends using data analytics techniques.

## Tools Used
- Python (Pandas)
- SQL
- Power BI
- Excel
- GitHub

## Project Workflow
- Data loading and cleaning using Python
- Exploratory Data Analysis (EDA)
- Business analysis using SQL
- Interactive Power BI dashboard
- Data-driven business insights

## Key Analysis
- Customer purchasing behavior
- Shopping trends
- Sales and purchase patterns
- Customer segmentation
- Product and category analysis
- Business insights and recommendations

## Project Objective
The objective of this project is to analyze retail customer behavior and shopping patterns to identify meaningful business insights and support data-driven decision-making.
